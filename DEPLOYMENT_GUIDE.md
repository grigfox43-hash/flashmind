# Инструкция по бесплатной публикации веб-приложения FlashMind AI

Ваше веб-приложение готово и протестировано! Ниже описаны 2 самых простых и 100% бесплатных способа опубликовать его в интернете.

---

## Вариант 1. Публикация через Vercel (Рекомендуется - за 1 минуту)

Vercel предоставляет бесплатный быстрый хостинг для сайтов на React/Vite.

### Шаг 1. Загрузите код в GitHub
1. Создайте репозиторий на [GitHub.com](https://github.com/new).
2. Загрузите проект в GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of FlashMind AI"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/flashmind-ai.git
   git push -u origin main
   ```

### Шаг 2. Разверните на Vercel
1. Перейдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **Add New...** -> **Project**.
3. Выберите ваш репозиторий `flashmind-ai`.
4. Нажмите **Deploy**.
5. Через 30 секунд Vercel выдаст готовую бесплатную ссылку на ваш сайт вида: `https://flashmind-ai.vercel.app`.

---

## Вариант 2. Публикация через Netlify Drag-and-Drop (Без Git - за 30 секунд)

Если вы не хотите использовать Git/GitHub:

1. Выполните сборку проекта локально в терминале:
   ```bash
   npm run build
   ```
   *В вашем проекте создастся папка `dist`.*

2. Перейдите на сайт [app.netlify.com/drop](https://app.netlify.com/drop).
3. Перетащите папку `dist` прямо в окно браузера на сайте Netlify.
4. Готово! Вы сразу получите бесплатную публичную ссылку на ваш сайт.

## Возможности приложения:
1. **Личный кабинет**: Каждый пользователь имеет свой профиль, учет статистики повторений, прогресс и рейтинг готовности к экзамену.
2. **ИИ Генератор карточек**:
   - Автоматическое извлечение понятий из PDF документов и текстовых конспектов.
   - Поддержка офлайн-генератора и внешнего API ключа Google Gemini.
3. **Система интервального повторения (SM-2)**:
   - 3D карточки с переворотом, озвучкой (TTS) и быстрым оцениванием (1-4).
4. **Аналитика готовности**:
   - Радар слабых тем с возможностью прицельного повторения проблемных карточек.
5. **Экзаменационный симулятор**:
   - Тестирование с выбором вариантов ответа и разбором ошибок.
